# Evidence 정책

## 기본 원칙

평가는 텍스트의 모양이 아니라 같은 수용 기준과 evidence bundle을 통과하는지로 판단한다.

## Day 1 기본 증거

- 핵심 플로우 실행 결과
- 스크린샷
- DOM snapshot 또는 HTML excerpt
- 브라우저 console 오류 기록
- network 실패 기록
- 서버 로그 excerpt

## 디자인 품질 증거

- 구현 전 비주얼 초안 이미지 또는 그 생성 프롬프트와 저장 경로
- UI 수정 전 기준 스크린샷
- 모바일 첫 화면 스크린샷
- 데스크톱 첫 화면 스크린샷
- 비주얼 초안과 실제 구현 화면의 차이 메모
- 수정 요청 반영 여부 메모
- 사용성 부작용 여부 메모
- CTA 계층과 시선 흐름 메모
- spacing / type scale 일관성 메모
- 국문 Pretendard, 영문 Inter 기본 폰트 적용 또는 테마 예외 근거 메모
- 피해야 할 패턴을 회피했는지에 대한 짧은 점검

## 브라우저 리뷰 루프

- UI 작업은 정적 코드 확인만으로 끝내지 않는다.
- 기능 작업도 정적 코드 확인만으로 끝내지 않는다.
- 실제 브라우저에서 데스크톱과 모바일 화면을 열고 본 뒤 수정한다.
- UI 수정 작업은 수정 전 화면과 수정 후 같은 화면을 비교하는 루프를 기본값으로 둔다.
- 가능하면 Codex browser 또는 Computer Use로 직접 확인하고 evidence를 남긴다.
- 리뷰 결과는 스크린샷, 기능 재현 메모, console/network 메모, 수정 후 비교 캡처로 남긴다.
